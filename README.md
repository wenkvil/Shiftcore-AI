# SHIFTCORE AI Demo

Static interactive prototype for demonstrating SHIFTCORE AI. All displayed plant metrics, incident records, and knowledge search responses are illustrative demo data. It is not connected to real industrial equipment or a live AI model.

## Deploy to Vercel

1. Create a new GitHub repository and upload `index.html`, `vercel.json`, and this README.
2. In Vercel, choose **Add New → Project**, import the repository, and deploy. No build command is required for this static site.
3. Copy the public `*.vercel.app` URL from the deployment and make a QR code pointing to that URL.

Alternative: use Vercel CLI from this folder with `vercel --prod` after logging in.
